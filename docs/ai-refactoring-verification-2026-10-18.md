# AI 리팩토링 웹·게임 시연 검증

검증일: 2026-10-18. 기존 최종보고서 v2 이후의 새 작업이며 고정 실험·과거 AI 예시와 구분합니다. Git HEAD는 `9f22e03728f173effcb778b3510ff2001bfe017b`를 유지했습니다. 커밋·브랜치·push·학교 제출·유료 API 호출은 수행하지 않았습니다.

## 실제 제품 동작

- 기존 정적 결과를 보존하는 결과 작업 화면과 별도 AI 탭을 추가했습니다.
- 선택한 후보의 파일과 지표로 제안 생성 → 실제 코드 차이 검토 → 해시 확인 후 별도 사본 적용 → 정적 재분석 → 소스 ZIP 다운로드를 연결했습니다.
- 공식 CLI 계정 연결과 사용자 소유 API 키 연결을 구현했습니다. ChatGPT 계정으로 로그인한 Codex의 실제 응답을 확인했습니다. Claude Code는 미설치, Gemini는 설치 탐지·연결 구현만 확인했습니다. API 3종은 네트워크 대역 검사이며 실제 과금 호출 검증은 아닙니다.
- AI가 임의 명령을 실행하거나 원본 파일을 직접 바꾸지 않습니다. 별도 검토 ID, 원본 SHA, 선택 파일 제한을 검사합니다. 실패해도 기존 정적 결과를 열 수 있습니다.
- 기존 메인·기록의 결과 링크는 새 작업 화면으로 연결하며 예시 결과와 기존 테마 전달을 유지했습니다. 저장된 고정 HTML은 수정하지 않았습니다.

## 검사와 한계

- **입력 동등성:** 원본 switch와 생성된 보조 함수의 실제 본문을 C로 컴파일했습니다. 키 0–255, 이벤트 4종, 키 매핑 2종, 이름 길이 4종, 너비 경계 4종의 32,768개 조합에서 인덱스·입력 상태·문자열·외부 호출 횟수가 같았습니다. 키·문자 범위·저장 길이 상수는 원본 헤더를 확인했습니다. 폭 계산·저장·텍스트 입력 종료 함수에는 대역을 사용했으므로 전체 저장 파일 호환성·장치 입력 변환 검증을 대신하지 않습니다.
- **재생 검사:** 무료 Freedoom 0.13.0 Phase 1의 내장 demo1/2/3을 전후 버전에서 화면·소리를 끄고 재생했습니다. 각각 7,117 / 7,089 / 6,042 게임 틱까지 완료했습니다. 고유 종료 요약을 확인했고, 원본 `G_CheckDemoStatus`가 정상 timedemo 종료에도 `I_Error` → `exit(-1)`을 호출하는 특성을 소스에서 확인했습니다. 종료 코드만으로 성공 처리하지 않았습니다. 프레임·게임 상태 해시 비교나 성능 평가를 수행한 것은 아닙니다.
- **웹 검수:** 브라우저에서 실제 제안·변경안 생성·적용·재분석·게임 빌드·실행 버튼을 사용했습니다. 결과 표와 실행 버튼의 페이지 이미지를 확인했습니다. 게임 프로세스·창 생성은 확인했습니다.
- **직접 플레이 미확인:** Windows 화면 캡처가 `FrameArrived timed out`으로 실패했고 창 재선택·활성화 후에도 `window capture timed out`으로 실패했습니다. 따라서 직접 이동·전투·저장·불러오기 조작을 검증했다고 주장하지 않습니다. 촬영 전 사용자 확인 순서는 시연 안내에 있습니다.
- **자동 검사:** 최종 전체 실행 357 passed, 80 skipped. .NET 8 경로를 실행 환경에 지정했습니다. 처음에는 x86 .NET 5 경로가 먼저 잡혀 C# 검사 4개가 실패했으나 시스템 설정을 바꾸지 않고 해당 실행의 경로만 바로잡아 통과했습니다. 경로 이탈·중복 치환·변경 크기·원본 보존·API 키 미저장·네트워크 대역·CSRF·삭제 기록 접근·재요청 상태·프로세스 시간 초과 정리·수정본 실제 재분석을 확인했습니다. 선택 도구/환경 검사 80개는 실행하지 않았으며, 자세한 이유는 JUnit 기록에 있습니다.
- **보존 검사:** 원본 게임 사본 전체가 기존 벤치마크와 일치하고 수정 사본의 차이는 메뉴 소스 한 파일뿐입니다. 승인된 중간보고서, 학교 HWP·제출 안내, 최종보고서 v2 Word·PDF는 기존 검증 기록의 SHA-256과 일치합니다.

## 시작과 증거

로컬 `docs/_demo_phase/START_DEMO.cmd`를 더블클릭합니다. Visual Studio 없이 결과 화면과 게임 실행 버튼을 사용합니다. 폴더의 `README_DEMO.md`에 시나리오·조작·다시 생성할 때의 주의점이 있습니다.

증거는 같은 폴더에 보관합니다: 실제 AI 기록 `actual_advice.json`, `actual_preview.json`, `actual_applied.json`; 수정 전후 전체 소스·분석·실행 파일; `verification/characterization/result.json`; `verification/replays/results.json`; `verification/preservation.json`; `verification/tests.xml`, `tests.log`; `verification/workbench-result.png`. 다운로드 URL·배포본 SHA는 `dependency_sources.json`에 있습니다. 별도 시연 자료는 기존 규칙에 따라 Git에서 제외되어 있습니다.

최종보고서 v2는 이 변경 전의 검증된 문서로 보존했습니다. 다음 문서 수정에서 이 사례를 추가할 경우 실제 AI 검증과 직접 플레이 미확인 범위를 구분하고, 새 표·그림·쪽 구성을 다시 렌더링해 확인해야 합니다.
