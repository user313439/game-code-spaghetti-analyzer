# 오류 안내 및 화면 보완 검수 (2026-10-05)

## 반영 범위

사용자가 요청한 예외 처리와 HTML 피드백을 반영했다. 첫 화면 제목·설명을 중앙에 배치하고, 소개를 목적 → 실제 대상 → 활용 순서로 정리했다. 서론의 MD/JSON 개발 기록 링크는 화면에서 제거했지만 기록은 보존했다. 공통 도움말은 ‘대시보드 읽는 법’으로 바꾸고 기본 접힘으로 만들었다. 그 밖의 표·그래프·카드와 점수 공식은 유지했다.

## 분석 상태

- `complete`: 선택된 언어와 범위의 파일 추출을 완료했다. 전체 구조의 완전한 이해·결함 판정·외부 DLL 해석을 보증하지 않는다.
- `partial`: 일부 접근/추출 실패 또는 문법 복구가 있다. 실패 항목은 제외하고 나머지 결과를 보존하며, 복구된 구문도 가능한 추출을 보존한다. 종료 코드는 3이다.
- `failed`: 지원 소스가 없거나, 분석 가능한 선언이 없거나, 입력 전체가 빈/주석 코드이거나, 실행/저장에 실패했다. 종료 코드는 1이다.

`analyze`는 AST의 파일 예외와 문법 진단을 `analysis_status.json` 및 점수 JSON에 연결하고 HTML에 분석 상태와 한계를 표시한다. 부분 분석은 상단에서 안내하고 상세 목록은 접어 두어 필요할 때 확인한다. `score-full`은 `analysis_status_full.json`을 별도로 남긴다. 저장 실패도 완료로 오인되지 않도록 쓰기 가능한 상태/점수 기록을 실패로 바꾸며 기존 HTML이 있으면 이전 또는 불완전 결과임을 안내한다. 디스크·권한 문제로 기록 자체를 쓸 수 없으면 콘솔 오류와 종료 코드가 최종 기준이다.

## 검증 방법 및 남은 범위

실제 C# 추출 통합 검사와 C/C++ 정상·문법 복구, 미지원/빈 입력, 일부/전체 파일 실패, 폴더 접근 실패, 저장 실패 및 HTML 이스케이프 회귀를 포함한다. 테스트는 `py -3.10 -B -m pytest tests/ -q -p no:cacheprovider`, 8사례 대조 및 화면 갱신은 `py -3.10 -B docs/_verification/run_safety_ui.py`로 재실행한다. .NET Debug 분석기를 먼저 빌드한다.

전체 테스트 105개와 후속 자동 검수 74개가 통과했다. .NET 빌드 오류는 없었고 기존 CS9057 버전 차이 경고 2개는 의존성을 바꾸지 않고 유지했다.
