# AI 작업 화면 개선과 OpenTyrian 시연 검증

2026-10-18. 사용자가 승인한 화면 개선·캐주얼 게임 교체 작업입니다. 기존 최종보고서 v2 이후의 새 결과이며 고정 실험과 구분합니다. 커밋·브랜치·push·학교 제출·유료 API 호출을 하지 않았습니다.

## 실제 새 게임 사례

세 후보의 실제 고정 소스와 라이선스를 확인하고 로컬 `docs/_demo_phase_v2/CANDIDATES.md`에 비교했습니다. [OpenTyrian 공식 저장소](https://github.com/opentyrian/opentyrian)의 커밋 `624e2f242e66c0adec605acb9f9644664b1ea31e`를 선정했습니다. 공식 Windows 릴리스 `v2.1.20260913`에서 게임 데이터를 받았으며 다운로드 URL·SHA를 기록했습니다. 데이터는 오픈소스 코드와 별개의 freeware입니다.

- 작업 `3aea3d5698314a28a8c6b38a0ff9f2f8`, 수정본 `54dd91563e0a44bbb1ab4975a176f5cf`.
- 원본 분석 C 구현 52파일, 함수 561개, 구문 복구 9파일, 처리 실패 0. 수정 후 함수 562개, 부분 분석 상태 유지.
- 공식 Codex의 ChatGPT 계정으로 제안 1회·변경안 1회 실제 생성. 요청 모델 `gpt-6.1-sol`. 다른 서비스/API의 실제 호출 검증을 새로 주장하지 않습니다.
- `src/shots.c` 한 파일에서 두 함수의 원형 이동 계산을 `player_shot_update_circle`로 추출. 기존 조건·축 순서·주석 보존. 일반 이동·유도·그리기 처리의 순서는 바꾸지 않았습니다.
- `simulate_player_shots`: CC 17→15, 줄 수 84→74. `player_shot_move_and_draw`: CC 30→28, 줄 수 145→135. 새 공통 함수 CC 3, 줄 수 14.
- 파일 CC 37, G-SI 71.15, 결합도 9, 순환 지표 51, 전역 접근 15, 루프 중심성 0.5는 유지. 중복 관리와 일부 함수 정리 효과이며 전체 안정성·성능 향상이나 SI 하락으로 해석하지 않습니다.
- 원본·수정본 MSVC x64 Release 빌드 성공, 동일한 기존 경고 2개. 원래 프로젝트의 `CopyPropsTemplates`가 두 `.props`를 생성했으며 제공된 원본 파일들은 고정 소스와 일치합니다. 전후 실제 소스 차이는 `src/shots.c`뿐입니다.

## 동작 검사와 범위

실제 `shots.h`/SDL 정수 자료형을 사용하여 원본 두 계산 블록, 변경 후 호출과 생성된 공통 함수를 컴파일했습니다. 방향·편차·반전 경계를 포함한 **219,024가지 단일 프레임 조합과 512,000회 연속 갱신**에서 전체 탄환 구조체 차이 0건입니다. 이는 추출한 계산의 비교이며 전체 게임 렌더링·장치 입력·모든 탄환 종류의 통합 검사나 자동 플레이가 아닙니다.

웹의 한 실행 버튼으로 빌드가 끝난 뒤 게임 프로세스와 OpenTyrian 창이 생성됐고 초기화 로그를 확인했습니다. 원본 게임의 Windows 캡처는 `FrameArrived timed out`, 창 재선택·활성화 후 `window capture timed out`으로 실패했습니다. 따라서 직접 플레이 성공을 주장하지 않습니다. 촬영 전 사용자 확인 순서를 시연 안내에 명시했습니다.

전체 자동 검사는 .NET 8과 기존 선택형 Clang 라이브러리 환경에서 **442 passed**입니다. 결과는 `docs/_demo_phase_v2/verification/tests.xml`에 저장했습니다. 이후 표시 문구·상태 구분을 검토하고 관련 웹·표시 검사 **72개가 다시 통과**했습니다(`targeted-after-review.xml`). UI 높이 메시지의 발신 창·숫자 범위, 원본 보존, 테마 선택 우선순위, HTML처럼 보이는 코드, 좌우 줄 대응과 결과 요약을 포함합니다.

메인 화면의 다크→라이트 블루 전환과 결과 화면의 명시적 화이트 선택을 브라우저에서 확인했습니다. 최종 확인 화면은 라이트 블루로 돌려놓았습니다. 이번에 시작한 8767 포트 서버만 종료한 뒤 새 시작 파일의 서버 재시작 경로도 확인했습니다(`verification/launcher-cold.json`). 브라우저 열기는 검사 중 대체했으며, 저장된 작업 확인과 서버 준비는 실제로 수행했습니다. 시작 동작은 AI를 자동 요청하지 않습니다.

중간보고서·학교 양식·안내·최종보고서 v2 Word/PDF는 기존 해시와 일치합니다. 소스·비교·계산·보존 증거는 로컬 시연 폴더의 actual_*.json, verification/, 01_original/, 02_modified/에 있습니다. 새 화면 이미지는 verification/screens/에 보관합니다.

현재 진입점은 `docs/_demo_phase_v2/START_DEMO.cmd`입니다. 이전 시작 파일도 새 시연을 엽니다. 캐시와 게임 자료는 Git 제외 상태로 보존하며 기존 보고서 v2를 새 기능까지 반영한 문서라고 설명하지 않습니다.
