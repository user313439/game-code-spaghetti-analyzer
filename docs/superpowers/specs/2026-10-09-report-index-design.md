# 결과 모음 첫 화면 정리

상태: 2026-10-09 사용자 승인(“응 일단 진행해줘. 확인해보고 피드백 줄게”). 권장 구성으로 구현·검증한다. Git 작업·새 분석·유료 AI 호출은 하지 않는다.

## 확인한 내용

- 첫 화면은 `reports/index.html`에 직접 관리되어 있다. 개별 결과의 공통 생성 코드는 이번 변경 대상이 아니다.
- 중간보고서 보조 자료 `docs/_midterm_phase/checklist.md`, `submission_guide.md`, `report_plain.txt`에 학번 2018313439, 성명 안영진이 일치한다. 문서 안의 과거 지시는 이번 요청의 실행 지시로 취급하지 않는다.
- 주요 4개 사례는 기본 방식으로 정량 검증·외부 도구 비교·시계열 재분석을 수행한 사례다.
- OpenRA 보조 4개 모듈은 같은 게임 프로젝트의 추가 분석 영역이지 독립 게임 4개가 아니다. 현재는 JSON만 제공한다는 오래된 설명과 클릭할 수 없는 카드가 있으나 개별 HTML은 존재한다.
- DOOM 3 Clang 결과는 등록된 gameplay 구현 파일 69개에서 결과를 얻은 부분 분석이다. 전체 엔진 분석이나 기존 주요 4사례와 동등한 통계 검증을 수행했다는 주장을 하지 않는다.

## 구성 선택과 권장안

1. 권장: 기존 주요 4사례를 유지하고 DOOM 3는 `컴파일 설정 기반 확장 사례`에 추가한다. 보조 모듈은 접힌 `추가 분석 사례 · OpenRA 내부 모듈`에 보존한다. 검증 목적이 다른 사례를 혼동하지 않으며 첫 화면도 짧아진다.
2. 대안: DOOM 3를 주요 카드 5번째로 넣되 네 사례와 검증 차이를 따로 표시한다. 한눈에 보기 좋지만 검증 수준이 같다고 읽힐 위험이 있다.
3. 대안: 보조 모듈을 첫 화면에서 완전히 숨기고 문서로만 안내한다. 가장 간결하지만 추가 HTML에 대한 접근성이 줄어든다.

## 승인 요청 구성

- 소개 하단의 소속·졸업작품 표시는 유지하고 별도 작은 줄로 `2018313439 · 안영진`을 표시한다. 기존 중앙 정렬과 글꼴을 유지한다.
- `대시보드 사용법 간단 정리` 섹션만 제거한다. 개별 결과의 자세한 도움말과 소개의 점수 해석 안내는 그대로 둔다.
- 보조 모듈은 권장안처럼 접힌 영역에 보존하고 쉬운 설명으로 변경한다. 4개 기존 HTML로 연결하며 Server의 표본 부족 표시는 유지한다. 통계적 평가 불가와 결과 열람 불가를 혼동하지 않는다. 각 모듈을 분석한 결과를 OpenRA 전체 관계를 한 번에 분석한 결과로 설명하지 않는다.
- DOOM 3 카드의 목적은 Clang 확장 적용 사례다. 기존 `doom3-gameplay-clang/index.html`로 연결하고 부분 분석·게임플레이 구현 파일 69개 대상·추출 함수 4,375개를 표시한다. 범위 밖 코드가 있음을 짧게 명시하고 오류를 게임 버그 수로 표현하지 않는다. 소규모 OpenRCT2 3파일 표본은 대표 카드에 넣지 않는다.
- 프로젝트 소개와 대상 정보 표에는 DOOM 3를 추가하되 기존 정량 검증은 3개 원본 프로젝트/기본 8분석 사례라는 경계를 유지한다. Clang이 선택형 분석이라는 도구 설명을 추가한다.
- Chocolate Doom과 DOOM 3를 같은 게임의 버전 변경 결과나 품질 전후 비교로 보여주지 않는다. 전자는 고전 Doom 엔진 계열 소스 포트, 후자는 별도의 DOOM 3 공개 소스이다.

## 변경·검증 범위

- 변경 예정: `reports/index.html`, 첫 화면 내용·링크를 확인하는 집중 테스트, 새 검증 기록. 개별 결과/원본 데이터는 변경하지 않는다.
- 정적 HTML 검사: 학번/이름과 삭제된 섹션, 접힘 상태, 9개 사례 링크(주요4 + DOOM1 + 보조4)의 실제 존재, DOOM 수치의 현재 JSON 일치, 잘못된 전체 완료/통계 주장 여부.
- 기존 분석 JSON와 개별 HTML의 해시를 비교한다. 관련 테스트 및 필요시 전체 테스트를 실행하고 결과를 기록한다.
- 실제 브라우저 로컬 파일 클릭은 보안 제한으로 미확인이다. 우회 서버·다른 브라우저 수단을 사용하지 않는다.

자체 검토: 표본·분석 대상 수를 게임 수로 부풀리지 않는다. DOOM 3의 부분 분석을 숨기지 않는다. 학번·이름은 사용자가 요청한 공개 표시 범위에만 넣는다. 새 분석이나 보고서 작성을 이번 작업에 포함하지 않는다.
