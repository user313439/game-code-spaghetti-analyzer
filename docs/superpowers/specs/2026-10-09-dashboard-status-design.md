# 분석 상태 안내 화면 정리

2026-10-09 사용자 승인: 게임 이름과 부제를 분리하고, 기존 상태 숫자를 유지하면서 항목별 툴팁과 접힌 원인 설명을 추가한다. 다른 게임에도 동일한 공통 렌더러를 적용한다.

- 완료·부분 분석·실패를 같은 상태 카드로 표시한다. 선택 범위의 완료는 전체 게임의 완전한 해석을 뜻하지 않는다.
- Clang: 구현 파일 단위, 등록, 추출, 미등록, 접근·추출 실패, 컴파일 오류·경고를 순서대로 표시한다. 숫자는 원본 상태 데이터에서 읽는다.
- 기본 분석: 같은 배치를 사용하되 컴파일 설정 등록·미등록과 컴파일러 진단은 `해당 없음`으로 표시한다. 구문 복구는 별도 항목이다. 없는 측정치를 0으로 만들지 않는다.
- 툴팁은 기존 `data-tooltip` 패턴을 사용하고 키보드 포커스에도 노출한다. 추출은 결과 수신이지 완전 해석이 아니다. 진단 수는 고유 게임 버그 수가 아니다.
- 원인 설명은 실제 진단 메시지로 식별할 수 있는 범주만 안내한다. 키워드 매크로 충돌, 멤버 함수 포인터 변환, 누락 헤더, 문자열 변환 경고 등에 일반적으로 적용하며 게임 이름을 조건으로 사용하지 않는다. 식별할 수 없으면 원인을 확정하지 않는다.
- 경로·전체 옵션·해시·긴 진단 목록은 화면에서 제거한다. 원본 JSON은 그대로 보존한다. 중요한 지원 한계는 접힌 `분석 범위와 한계`에 남긴다.
- 제목은 이름, 부제, 리포트 종류를 별도 줄로 표시한다. 선택형 `--project-subtitle`은 정식 실행 명령에도 전달한다.
- 현재 11개 사례 HTML을 표시 부분만 갱신한다. 원본 분석 시각, 점수·차트 데이터와 모든 JSON, 과거 검수 기록, 모음 화면은 변경하지 않는다.
- 실제 브라우저의 로컬 파일 접근은 보안 정책에 의해 차단되었으므로 우회하지 않는다. 자동 검증은 HTML 구조·툴팁·접힘 상태·JavaScript 문법·데이터 보존으로 한정하고 실제 클릭 점검은 사용자 확인이 필요하다.
- 커밋·브랜치·푸시는 하지 않는다.
