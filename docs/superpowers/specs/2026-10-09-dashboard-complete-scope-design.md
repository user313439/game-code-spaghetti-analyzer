# 완료 표시와 분석 범위 안내 재정리

상태: 2026-10-09 사용자 승인(“응 부탁할게”). 아래 기준으로 화면을 수정하고 검증한다. Git 쓰기와 추가 실게임 분석은 수행하지 않는다.

## 요청

- 분석 완료에도 100%를 표시한다.
- 대시보드 읽는 법은 점수·등급·화면 사용법 중심의 기존 구성으로 되돌린다.
- 완료 카드에도 부분 분석과 같이 접힌 분석 범위와 한계를 표시한다.
- OpenRCT2의 Clang 3파일 결과가 전체 게임 평가를 대신하는지 설명한다.

## 권장 표시

- 완료 제목은 `분석 완료 · 100%`로 표시하고 바로 옆 대상 범위와 툴팁에서 선택한 분석 대상 기준임을 밝힌다. 정확도, 전체 저장소 커버리지, 게임 빌드 성공률 또는 무결함 비율로 표현하지 않는다.
- 기본 분석의 100%는 기본 방식의 선택 범위 분석 완료 상태를 뜻한다. 컴파일러 진단을 수집하지 않았으므로 오류·경고 0으로 바꾸지 않는다.
- Clang 완료에서도 등록되어 실제 선택된 입력 기준이며 미등록 입력과 헤더 본문의 제외는 그대로 명시한다. 오류·추출 실패가 없어도 경고가 있을 수 있다.
- 기존 부분 Clang 카드의 `컴파일 오류 없는 파일 비율`은 현재 산식을 유지한다. 완료의 상태 표시와 달리 파일 기반 진단 지표라는 라벨을 유지하고, 두 수치 모두 전체 게임 분석률이 아님을 안내한다. 기본 부분 분석에 없는 컴파일러 비율을 만들지 않는다.
- 완료 카드에는 `분석 범위와 한계` 하나를 기본 접힘으로 복원한다. 중복 `분석 상태 설명`은 복원하지 않는다. 기존 완료 경고의 상세 설명은 이 접힌 영역 안에 보존한다.
- 도움말에 이전 변경으로 추가한 지원 범위·경고 목록은 상태 카드로 옮기고 원래 점수·등급·조작 설명은 보존한다. tooltip의 `이번 진단:` 줄바꿈도 유지한다.
- 공유 렌더러와 관련 테스트만 변경하고 기존 11개 HTML의 CSS·도움말·상태 영역을 갱신한다. 원본 분석 JSON, 지표·점수·스크립트·그래프·분석 시각은 변경하지 않는다.

## OpenRCT2의 실제 범위

- `reports/openrct2-clang-sample`은 Guard.cpp, Path.cpp, String.cpp 3개 등록 입력으로 Clang 기능을 검증한 보조 결과다. core 폴더의 나머지 28개 구현 파일도 등록되지 않았다. 이 파일들을 게임 전체를 대표하는 핵심 코드라고 부르지 않는다.
- 위 표본의 완료는 등록된 3개 입력 기준이며 core 전체나 저장소 전체 완료가 아니다. 3파일 결과의 의존성 순환·결합도는 선택 집합에 한정되어 제외 파일을 통과하는 연결을 놓칠 수 있다. 점수도 표본 내부 상대 순위라 본격 결과와 직접 비교하지 않는다.
- `reports/openrct2`는 별도의 기본 방식 본격 결과이며 src/openrct2 범위의 544개 cpp 파일과 636개 점수 단위다. 현재 상태 기록은 36개 구문 복구 파일을 가진 부분 분석이다. 모든 언어·헤더·외부 라이브러리·플랫폼 설정을 완전히 해석한 결과가 아니다.
- 권장: 3파일 표본은 검증 근거로 보존하고 대표 시연·평가에는 넓은 범위 결과를 사용한다. Clang 방식의 넓은 범위 분석 확장은 호환 컴파일 설정·외부 의존성·대상 플랫폼 준비와 별도 실행/검수가 필요하므로 이번 화면 변경에 끼워 넣지 않는다.
- 표본 화면 부제는 `Clang 기능 검증용 · 선택한 3개 구현 파일`처럼 명확하게 표시하는 것을 제안한다. 전체 게임 100%처럼 읽히지 않도록 선택 수를 유지한다.

## 검증 체크리스트

- 완료 100%의 선택 범위 툴팁과 기본/Clang 차이를 테스트한다.
- 완료는 한계 설명 1개, 부분은 원인·한계 2개가 모두 기본 접힘인지 테스트한다.
- 도움말은 기존 점수·등급·조작 내용이고 한계/경고 설명은 상태 카드에 보존되는지 테스트한다.
- 부분 Clang 산식과 툴팁 줄바꿈이 유지되는지 확인한다.
- HTML의 허용 영역 외 바이트와 기존 분석 JSON이 보존되는지 검사한다.
- 전체 기존 native-enabled 테스트를 실행한다. 실제 브라우저 조작은 로컬 파일 접근 제한 때문에 미확인으로 명시하고 우회하지 않는다.

자체 검토: 완료 상태의 100%와 컴파일 오류 없는 파일 비율의 의미를 분리했다. 전체 게임 분석률을 새로 주장하지 않는다. 검증용 표본을 삭제하거나 새로운 분석을 완료했다고 표기하지 않는다. 추가 범위 확장은 별도 판단 항목으로 남긴다.
