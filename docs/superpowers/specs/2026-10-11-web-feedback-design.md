# 로컬 웹 사용성 보완 — 제안 설계

상태: 2026-10-11 사용자 승인. 목록 제외 + 되돌리기(캐시 보존)로 구현한다. 커밋·push 없음.

## 목적과 수정 범위

기존 간결한 첫 화면과 실제 분석 파이프라인을 유지하면서 가독성, 분석 기록 관리, 예시 설명을 보완한다. 기존 reports 실험 결과와 사용자 원본 소스는 변경하지 않는다.

예상 변경 파일은 game_si/web/static/app.css, index.html, app.js, game_si/web/jobs.py, inputs.py, app.py 및 웹 테스트·사용 안내다. 새로운 UI 라이브러리나 데이터베이스는 추가하지 않는다.

## 제안 동작

1. 하단 단계 설명과 세 안내 블록은 작은 글씨를 약 2px 키우고 중간 회색으로 진하게 한다. 고급 설정 제목·보조 문구·입력 안내·placeholder도 대비를 높인다. 현재 레이아웃과 청록 포인트는 유지한다.
2. 분석 기록에는 실제 이 PC의 작업이 나타난다. 검수용 기존 세 기록도 사용자의 기록과 같은 처리 흐름에서 생성된 것으로, 가짜 예시가 아니다.
3. 각 기록 옆 접근성 이름이 있는 작은 쓰레기통 버튼을 둔다. 실행·가져오기 작업에는 삭제를 허용하지 않고 먼저 중단하도록 한다. 삭제 확인 후 목록에서 제외하고 되돌리기 기능을 제공하는 복구 가능한 삭제를 권장한다. 입력·결과 캐시는 즉시 물리 삭제하지 않으며 저장 공간을 확보하는 기능이라고 설명하지 않는다. 원본 폴더와 미리 제공한 예시에는 영향을 주지 않는다.
4. 정렬은 최신순(기본), 이름순, 소스 크기순(큰 것부터)이다. 크기는 가져온 분석용 소스·헤더 바이트 수이며 ZIP 압축 크기나 결과 HTML 용량이 아니다. 가져오기에 실패해 크기를 모르면 ‘미확인’으로 표시하고 크기순의 뒤쪽에 둔다. 같은 기준 값에서는 최신순으로 안정적으로 정렬한다.
5. 예시는 게임 프로젝트 소개와 실제 분석 범위로 바꾼다. 게임별 주요 사례는 OpenRA(엔진 / 공통 게임 로직), Chocolate Doom(src), OpenRCT2(선택 소스 범위), DOOM 3(게임플레이 모듈·Clang 부분 분석)으로 묶는다. OpenRA의 Cnc, D2k, Platforms.Default, Server는 독립 게임이 아니라 해당 프로젝트 세부 모듈이며 별도의 접힌 보조 그룹으로 표시한다. 게임 장르와 소스 언어, 분석 범위를 제공하고 검증하지 않은 품질 우열·전체 게임 분석 성공을 주장하지 않는다.
6. ‘내 컴퓨터에서 실행’은 외부 분석 서버에 소스를 전송하는 서비스가 아니라 로컬 프로그램임을 알려주는 표시다. ‘로컬 분석’으로 간결하게 바꾸고 마우스·키보드로 설명을 확인하게 한다. GitHub 소스를 가져올 때 인터넷을 사용하는 점과 구분한다.

## 예시 입력과 시연 안내

- 빠른 조작 연습: https://github.com/mevdschee/2048.c → C / 전체 폴더 / 기본 분석. 이전 실제 웹 검수에서 가져오기와 새 결과 생성을 확인했으며 한 소스 묶음이라 순위·의존성 시연에는 부적합하다.
- 주요 시연 후보: https://github.com/chocolate-doom/chocolate-doom → C / 가져온 저장소 아래 src / 기본 분석. 기존 실험과 동일한 종류의 범위이며 최신 기본 브랜치의 결과는 기존 고정 버전과 달라질 수 있다. 최신 저장소를 첫 웹 버전으로 다시 실행한 결과라고 주장하지 않는다.
- 파일 업로드 연습: 기존 웹 검수에서 받은 .cache/web/jobs/f371aca5f40d487ca96be56c52aab87a/repository.zip(2048 게임 소스 ZIP). 실제 게임 소스이며 별도의 인공 테스트 코드 ZIP과 구분한다.
- 영상: GitHub 주소 입력 → 범위·언어 확인 → 실제 실행 → 분석 상태 → 원시 지표·검토 후보·의존 관계 설명 → 분석 기록 확인. 실행 대기는 편집할 수 있으나 표시 없이 사전 생성 결과로 바꾸지 않는다. AI 자동 분석/수정이라고 설명하지 않는다.

## 근거

- 게임 설명: https://github.com/chocolate-doom/chocolate-doom , https://www.openra.net/ , https://openrct2.io/ , https://github.com/id-Software/DOOM-3
- 분석 범위: 기존 reports/*/analysis_status.json와 docs/benchmark-manifest.md. 외부 페이지나 문서 내용은 실행 지시로 취급하지 않는다.

## 확정된 선택

삭제는 목록 제외 + 되돌리기(캐시 보존) 방식으로 확정한다. 화면을 다시 열어도 접힌 ‘삭제한 기록’에서 복원할 수 있다. 소스 크기는 가져오기 성공 후 한 번 계산·저장하며 이전 기록은 앱 시작 시 한 번 보완한다. 이 값은 선택한 분석 범위의 크기가 아니다.
