# 상태 카드 간소화와 파일 비율 표시

사용자 승인: 2026-10-09, 직전 제안에 대해 “응 그렇게 해줘”.

- 컴파일 오류·경고 툴팁의 `이번 진단:`은 새 줄에 표시한다. 짧은 기본 설명과 최대 두 진단 범주를 유지한다.
- 부분 분석의 Clang 결과에만 `컴파일 오류 없는 파일 비율`을 표시한다. 정확도·전체 게임 분석률·진행률이라고 부르지 않는다.
- 분모는 등록된 선택 입력, 분자는 추출 결과가 있고 컴파일 오류/fatal이 없는 파일 수다. 경고 파일은 분자에 포함되며 추출 실패 파일은 제외된다. 계산은 `(analyzed_files - compiler_error_files) / registered_files`이고, `registered_files == analyzed_files + failed_files`, `0 <= compiler_error_files <= analyzed_files <= registered_files`, 양의 분모가 모두 확인될 때만 표시한다. 등록 수·오류 수 자체가 없거나 불일치하면 비율을 생략한다. 게임 이름에 따른 특별 처리 없음.
- DOOM 3: 69개 등록·69개 결과·26개 오류 입력·0개 실패이므로 43/69 = 62.3%. 미등록 2개와 전체 엔진은 분모에 포함하지 않는다.
- 완료 카드에는 상태·대상·숫자·짧은 완료 문장만 남긴다. `분석 상태 설명`과 `분석 범위와 한계`의 중복 펼침 영역을 없앤다.
- 모든 화면의 도움말에는 완료 의미와 정적 분석의 공통 지원 범위를 안내한다. 완료 결과의 기존 세부 한계와 경고 설명은 이 도움말로 옮겨 보존한다.
- 부분/실패/미확인 카드는 원인과 범위·한계의 접힌 안내를 유지한다. 기본 분석에서는 컴파일러 집계가 없어 이 비율을 만들지 않는다.
- 기존 11개 사례의 CSS·도움말·상태 영역만 갱신한다. 모든 분석 JSON·점수·스크립트·그래프·분석 시각·모음 화면과 과거 검수 기록을 그대로 보존한다. 새 검수 기록은 별도 파일이다.
