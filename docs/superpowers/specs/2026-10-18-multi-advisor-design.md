# 다중 후보와 작업 진행 표시

사용자가 요청한 화면 구분, 최대 5개 후보 선택, 실제 진행 표시, 결과 강조, 실행 버튼 우측 하단 배치를 구현한다. 기존 기록과 학교 자료는 보존하며 Git 작업·유료 API 호출은 하지 않는다. 명확히 요청한 범위는 현재 세션에서 진행한다.

G-SI 내림차순에서 파일 중복을 제외한 상위 5개를 먼저 제시한다. 다른 후보도 펼쳐 선택할 수 있지만 선택은 서로 다른 파일 5개까지다. 기존 단일 후보 기록도 그대로 표시한다. 점수는 상대 검토 순위이며 AI 수정 가능성이나 예상 개선율로 바꾸지 않는다.

선택한 후보·소스 묶음을 한 번의 AI 요청에 전달한다. 결합 입력은 360KB까지 제한한다. 제안도, 변경안도 각각 요청 한 번이며 선택 파일 외 수정은 거부한다. 정확한 선택 집합과 모든 원본 해시가 일치해야 다음 단계로 진행한다. 모든 변경은 함께 검토하고 별도 사본 하나에 적용·재분석한다. 안전한 변경이 없는 파일은 실제 변경 파일 수와 구분한다.

진행 정보는 서버의 실제 단계와 시작 시각을 따른다. 외부 AI 응답 대기는 움직이는 미확정 막대와 경과 시간으로 표시하고 응답률을 꾸미지 않는다. 예상 시간은 동일 작업·연결·후보 수의 실제 이력이 있을 때만 제공한다. 적용 승인 직후 03으로 이동해 사본 생성→재분석→결과 정리를 보여준다. 실패도 그 화면에서 확인한다.

제안은 번호·강조 소제목 영역과 별도의 답변 영역으로 분리한다. 완료 결과는 강조 제목·확인 상태·실제 변경 수·함수 변화·파일별 점수 전후를 먼저 보여준다. 여러 파일을 첫 파일 수치로 대표하지 않는다. 게임 실행은 게임 확인 카드의 우측 하단에 배치하고 작은 화면에서는 전체 폭으로 바꾼다.

실제 게임 시연 기록은 덮어쓰지 않는다. 다중 선택·실패·진행 검증은 별도의 명시적 검사 작업과 대체 AI 응답으로 수행하며 실제 AI 분석 증거로 제시하지 않는다.
