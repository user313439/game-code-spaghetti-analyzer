# 다중 후보 선택·진행 표시·결과 강조 검수

2026-10-18. 기존 화면 개선 이후의 추가 피드백을 반영했다. 실제 게임 리팩토링 실험을 새로 수행한 기록과 구분한다.

## 반영 내용

- 제안의 질문/소제목은 번호가 있는 별도 배경 영역, 답변은 본문 영역으로 분리했다. 넓은 화면은 좌우, 좁은 화면은 위아래 배치를 사용한다. 실제 표시를 blue/dark/light에서 확인했다.
- 파일 중복을 제외한 G-SI 상위 5개를 기본 추천하고 최대 5개 파일을 선택한다. 이전 선택을 유지하되 카드도 5개 이내로 보여준다. 다른 후보는 펼쳐서 추가한다. 점수는 상대 검토 우선순위이며 예상 개선율로 표현하지 않는다.
- 선택 파일 묶음에 대해 제안 1회·변경안 1회의 요청을 보낸다. 파일당 180,000바이트, 합계 360,000바이트와 기존 12개 교체 항목 제한을 적용한다. 입력량과 계정 사용량이 늘 수 있음을 생성 버튼 아래에 안내한다.
- 선택 집합과 모든 원본 해시가 같아야 다음 단계로 간다. 선택 외 수정, 같은 파일 중복, 여섯 번째 선택, 검토 중 원본 변경, 변경하지 않은 참고 파일의 변경도 거부한다. 선택 수와 실제 변경 파일 수는 구분한다.
- 제안·변경안·적용에 실제 단계 막대와 경과 시간을 표시한다. AI 응답 및 재분석은 미확정 구간으로 움직인다. 표시 값은 완료 단계 수이며 시간상 백분율이 아니다. 같은 종류·연결·모델·선택 수의 최근 5회 이내 실제 완료 시간 중앙값만 예상 시간의 근거로 사용한다. 새 모델에는 다른 모델의 이력을 재사용하지 않는다.
- 적용 승인을 받으면 즉시 03으로 이동한다. 결과는 강조 제목·원본 보존/적용/재분석 상태·변경 파일 수·복잡도 감소 함수 수를 먼저 표시하고 모든 비교 항목의 G-SI/원시 지표를 보여준다. 첫 파일만 전체 결과처럼 설명하지 않는다.
- 실제 적용 사실과 AI가 제안했던 방향을 분리했다. 제안문의 ‘합니다’를 ‘했습니다’로 치환해 검증된 변경 설명으로 쓰지 않는다.
- 게임 실행은 카드 우측 하단에 배치했다. 현재 수정본과 빌드된 수정본이 다르면 이전 버전의 검사 수치를 표시하지 않도록 프런트엔드와 백엔드를 함께 수정했다.

## 실제 검사와 증거

`docs/_verification/2026-10-18-multi-advisor/`에 증거를 보관한다.

- 전체 자동 검사 **456 passed, 실패/건너뜀 0**, `tests.xml`. .NET 8과 기존 선택형 Clang 라이브러리 환경을 사용했다. 마지막 관련 웹 검사도 86개 통과했다(`targeted.xml`). JS 구문과 Git diff 공백 검사도 통과했다.
- API 검사: 두 파일을 한 요청으로 전달, 사본에 함께 적용·재분석, 원본 보존, 선택/해시/크기 제한, 선택 외 수정 거부, 실제 이력과 모델 구분, 오래된 게임 검증 문구 차단.
- 브라우저 검사: 별도 8768 포트와 별도 캐시의 7개 작은 C 검사 소스를 실제로 정적 분석했다. **AI 응답은 대체 응답이며 실제 AI 호출이 아니다.** 화면 제목과 답변에 검사 전용임을 표시했다. 5개 선택→제안→좌우 5파일 비교→승인→03 진행 표시→5파일 재분석까지 확인했고 `fixture-applied.json`에 상태를 저장했다. 일부러 넣은 대기 시간도 실제 모델의 성능 측정값으로 사용하지 않는다.
- 여섯 번째 선택 차단과 API 키 누락 오류를 브라우저에서 확인했다. 같은 검사에서 다시 제안 생성 시 ‘이전 1회 기준 약 7초’가 표시됐지만 이는 지연을 넣은 검사 전용 이력이다. 실 서비스 시간으로 안내하지 않는다.
- 실제 시연 작업은 읽기 전용으로 blue/dark/light를 확인했다. 기존 라이브 수정본 `4da6004c40ca4fd29a5e06a92e5fe698`의 AI 상태 파일은 검사 시작 시 SHA와 동일하다. 앞서 보존한 기준 실험 `54dd91563e0a44bbb1ab4975a176f5cf`도 새 다중 파일 실험이라고 설명하지 않는다.
- 게임 카드 우측/하단과 버튼 사이 안쪽 여백은 각각 29px이며 해당 화면의 페이지 가로 넘침은 없었다. 좁은 화면은 기존 미디어 규칙과 열/줄바꿈을 코드로 검토했으나 브라우저 도구가 화면 크기 변경을 제공하지 않아 별도 모바일 크기의 캡처는 수행하지 못했다.

주요 화면은 `screens/advice-blue.png`, `advice-dark.png`, `advice-white.png`, `results-blue.png`, `game-action-blue.png`이다. `fixture-*.png`는 검사 응답의 진행 표시이며 게임 실험 증거가 아니다.

새 유료 API·구독 AI 호출, 게임 코드 추가 수정·실행, 문서 v2 수정, 커밋·브랜치·push·학교 제출은 하지 않았다. 기존 Word/PDF와 학교 원본도 SHA로 다시 확인한다. 현재 시작 파일은 이전과 같은 `docs/_demo_phase_v2/START_DEMO.cmd`다.
