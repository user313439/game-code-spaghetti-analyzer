# 최종판 재검증 반영 전 결과 보관

이 폴더는 2026-10-03에 최신 재검증 결과를 `reports/`에 반영하기 **직전의 자료**를 보존한다. 파일의 원래 실험·작업 날짜가 2026-10-03이라는 뜻이 아니다.

- 기존 점수 JSON(정밀도 보존용 `raw_exact` 추가 전), 튜닝 및 비교·시계열·Full 결과를 보관한다.
- 이전 튜닝은 계산·분리 기준이 달라 최신 결과와 같은 조건의 성능 변화로 비교하면 안 된다.
- 현재 최종판 기준은 [최신 검증 문서](../../../docs/final-verification.md)와 `reports/verification-2026-10-03.json`이다.
- AI 가이드 JSON은 교체하지 않았으며 원래 사례 폴더에 남아 있다. 생성 당시의 지표에 근거한 예시다.
- 과거 커밋 날짜나 실험 기록을 수정·삭제하여 작업 시점을 바꾸지 않는다.
