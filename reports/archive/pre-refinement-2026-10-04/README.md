# 보완 전 결과 보관본

2026-10-04 한국시간에 최신 보완 결과를 반영하기 직전의 결과 파일과 기존 AST·메트릭 중간 파일을 보관한다. 이 날짜는 보관 날짜이지 원본 실험이나 파일 생성 날짜를 뜻하지 않는다.

호출·식별자 수정 전 수치이며 최신 결과로 인용하지 않는다. 중간보고서 승인본은 이 보관본과 별도로 원위치에 그대로 유지한다. 최신 근거는 `docs/refinement-review.md`, 이전 단계 검증 근거는 `docs/final-verification.md`를 참조한다. 파일이 이미 있으면 재실행해도 덮어쓰지 않는다.
