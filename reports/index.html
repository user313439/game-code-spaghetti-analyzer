Game Code Spaghetti Analyzer

게임 엔진 기반 프로젝트의 C# 코드를 정적 분석하여 함수·클래스·파일·모듈 단위의 의존성과 게임 특화 위험을 정량화하는 도구입니다. 성균관대학교 소프트웨어학과 졸업작품 (2026-1).

아래는 본 도구를 두 개의 오픈소스 게임 엔진 모듈에 적용한 결과입니다. 각 카드를 클릭하면 해당 프로젝트의 상세 대시보드(클래스별 G-SI 점수, 의존성 그래프, 순환 의존성 묶음 등)로 이동합니다.

대시보드는 외부 라이브러리 의존성 없이 단일 HTML 파일로 동작하며, 모든 데이터는 페이지 내부에 임베드되어 있어 인터넷 연결 없이도 정상 동작합니다.

대시보드 사용법 간단 정리

각 대시보드 페이지에서 다음을 확인할 수 있습니다.

  • Project Health — 프로젝트 전체 종합 점수와 등급 (한 화면에서 가장 큰 카드).
  • Summary 카드 6개 — 분석 규모와 위험 신호 요약.
  • 등급 분포 차트 — 모든 클래스를 A~E로 나눈 비율.
  • Hotspot Table — 가장 위험한 클래스 목록. 등급 필터·텍스트 검색·컬럼 정렬 모두 동작합니다.
  • Dependency Graph — 위험 클래스 주변 의존성 시각화. 마우스 휠 확대/축소, 드래그 이동, 노드 hover로 상세 정보.
  • Cycle Explorer — A→B→C→A 식으로 순환 참조에 빠진 클래스 묶음 목록.
  • Module Summary — 폴더 단위 집계.

각 섹션 제목 옆의 「ⓘ 이 섹션이 뭔가요?」 버튼을 누르면 그 섹션의 자세한 설명이 펼쳐집니다.
